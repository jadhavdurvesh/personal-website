# Durvesh Jadhav — Personal Portfolio

A futuristic, responsive personal portfolio built with Next.js, TypeScript and Tailwind CSS.

## Stack
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

This is a static portfolio website. It does not use a database, authentication, or a website backend. Email infrastructure is a separate project.
